EN: Alpinoxi Client and its open-source code.

This project is a lightweight version of the Minecraft launcher known as OneClient/OneLauncher. Resource-intensive add-ons—such as PolyPlus (along with all features specific to the original OneClient)—have been removed and replaced with the Essential mod. Additionally, EvergreenHUD has been excluded; therefore, there is no HUD (heads-up display) present. Please note that this project has no affiliation with the original OneClient; it simply utilizes the source code to provide a new launcher and has neither been endorsed nor verified by the Polyfrost team.

As the code is not yet fully polished, the initial (beta) version has not been released. However, the Alpinoxi team aims to address these shortcomings as soon as possible. (Regarding any forks you may create: the features they offer can be incorporated into the project, provided that the necessary permissions are obtained.)

Since the first beta version has not yet been released, the project is not currently digitally signed; this will be resolved shortly. Alpinoxi Client is intended to be a fully functional, independent launcher. Furthermore, if you choose to compile the first beta yourself, we would be happy—with your permission—to include your build in the project’s official releases. This helps the project grow! If you require assistance with the compilation process, you may refer to the instructions provided within the Polyfrost source code.

TR: Alpinoxi Client ve açık kaynak kodu.

Bu proje, OneClient/OneLauncher olarak bilinen Minecraft başlatıcısının (launcher) hafifletilmiş bir sürümüdür. PolyPlus (ve orijinal OneClient'a özgü tüm özellikler) gibi sistem kaynaklarını yoğun kullanan eklentiler kaldırılmış ve yerlerine Essential modu eklenmiştir. Ayrıca, EvergreenHUD de çıkarılmıştır; dolayısıyla herhangi bir HUD (ekran üstü bilgi göstergesi) bulunmamaktadır. Lütfen bu projenin orijinal OneClient ile hiçbir bağlantısı olmadığını unutmayın; proje, yalnızca kaynak kodunu kullanarak yeni bir başlatıcı sunmaktadır ve Polyfrost ekibi tarafından onaylanmamış ya da doğrulanmamıştır.

Kod henüz tam anlamıyla mükemmelleştirilmediği için ilk (beta) sürüm henüz yayınlanmamıştır. Ancak Alpinoxi ekibi, bu eksiklikleri en kısa sürede gidermeyi hedeflemektedir. (Oluşturabileceğiniz çatallamalar/fork'lar ile ilgili olarak: gerekli izinlerin alınması koşuluyla, bu çatallamalarda sunulan özellikler ana projeye dahil edilebilir.)

İlk beta sürümü henüz yayınlanmadığından, proje şu an için dijital olarak imzalanmamıştır; bu durum kısa süre içinde çözülecektir. Alpinoxi Client, tam işlevsel ve bağımsız bir başlatıcı olmayı amaçlamaktadır. Ayrıca, ilk beta sürümünü kendiniz derlemeyi tercih ederseniz, izninizle, oluşturduğunuz bu derlemeyi projenin resmi sürümlerine dahil etmekten memnuniyet duyarız. Bu, projenin büyümesine katkıda bulunur! Derleme süreciyle ilgili yardıma ihtiyaç duyarsanız, Polyfrost kaynak kodunda yer alan talimatlara başvurabilirsiniz.
