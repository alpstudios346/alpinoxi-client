THE FOUNDATION

Everything starts with a better launch.

01

C++ native

One .exe built with CMake and MSVC. The launcher keeps its distance from Minecraft's Java process, and opens in the time it takes to click.

02

Three ways in

Microsoft, Ely.by and offline profiles. Real sign-in flows with PKCE, and a cracked name that produces the exact same UUID Minecraft does.

03

Memory that makes sense

Aikar's G1 flags, trimmed for a client, scaled to the heap. Never more than half the machine, never below a playable floor.

KEYS

The keys you reach for.

Every one of them can be rebound in Settings, and a key already taken is refused instead of quietly firing two things at once.

ShiftTab

Friends and worlds

Opens the friend list beside the worlds that are open right now, with a join button on anyone who has one.

Esc

Close the HUD

Puts down a HUD element being dragged, and otherwise closes the HUD. Always a way back out.

ShiftH

Edit the HUD

Drag any element where you want it, pick its corner, and toggle each one on or off.

Tab alone stays the game's player list, F1 stays the debug screen, and nothing is taken from the game without a modifier.

LOADERS

Four ways to run a version.

Each loader is resolved from its own official metadata, so a new Minecraft release needs no launcher update.
