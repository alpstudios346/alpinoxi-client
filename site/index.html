THE FOUNDATION

Everything starts with a better launch.

01

Rust-native

No Electron shell. The launcher is a native Rust desktop app, kept separate from Minecraft’s Java process.

02

Your accounts

Microsoft, Ely.by and clearly labelled offline profiles are part of the experience from the beginning.

03

Intentional memory

Balanced, Performance and custom RAM profiles give you control instead of unlimited memory guesses.
