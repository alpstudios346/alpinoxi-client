THE FOUNDATION

Everything starts with a better launch.

01

C++ native

One native binary, no runtime shell. The launcher stays separate from Minecraft's Java process and starts in the time it takes to click.

02

Your accounts

Microsoft, Ely.by and clearly labelled offline profiles. Official sign-in flows, and the last account you used is the one you come back to.

03

Intentional memory

Balanced, Performance and custom RAM profiles, capped at what the machine can actually give — never an unbounded guess.

LOADERS

One launcher, three mod loaders.

Each loader is resolved from its own official metadata, so a new Minecraft release needs no launcher update.
